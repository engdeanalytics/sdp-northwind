# sdp_northwind

The 'sdp_northwind' bundle was generated by using the Lakeflow Pipelines template.

## Getting Started

## Repository layout

- `src/models/staging`: staging materialized views that read from raw source schemas.
- `src/models/intermediate`: intermediate transformations.
- `src/models/marts`: published marts.
- `src/scripts`: utility scripts that are not part of the Lakeflow pipeline source.

The bundle deploys only `src/models/**` as Lakeflow Spark Declarative Pipeline source code. Local `.gitkeep` placeholders are excluded from bundle sync so they are not treated as pipeline source files.

## Catalog and schema design

The bundle follows a dbt-style target pattern:

- Raw source data is read from the `raw` catalog by default.
- Development outputs are deployed to the `dev` catalog and the active developer schema, `${workspace.current_user.short_name}`.
- Production outputs are deployed to the `prod` catalog.
- In development, all model layer schema variables resolve to the active developer schema.
- In production, model layer schema variables resolve by folder/layer: `staging`, `intermediate`, and `marts`.

The pipeline injects these values into SQL files through Lakeflow pipeline configuration parameters:

- `${raw_catalog}`
- `${target_catalog}`
- `${target_schema}`
- `${staging_schema}`
- `${intermediate_schema}`
- `${marts_schema}`
- `${erp_source_schema}`

To deploy and manage this bundle, follow these steps:

### 1. Deployment

- Click the **deployment rocket** 🚀 in the left sidebar to open the **Deployments** panel, then click **Deploy**.

### 2. Running Jobs & Pipelines

- To run a deployed job or pipeline, hover over the resource in the **Deployments** panel and click the **Run** button.

### 3. Managing Resources

- Use the **Add** dropdown to add resources to the bundle.
- Click **Schedule** on a notebook within the bundle to create a **job definition** that schedules the notebook.
